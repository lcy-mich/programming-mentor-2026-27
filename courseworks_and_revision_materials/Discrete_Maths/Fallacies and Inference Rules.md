Fallacies and Inference Rules

Appeal to Ignorance
- argument that it must be true as you can't prove false

False Dilemma
- presenting false number of alternatives

Anecdotal
- using isolated example or personal experience instead of solid argument

correlation 
- measurement of relation between two variables

causality
- cause and effect relationship between two variables
- if A then B, B if A
