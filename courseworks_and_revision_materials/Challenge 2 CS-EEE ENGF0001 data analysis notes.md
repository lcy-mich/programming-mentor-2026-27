For anomaly detection, hysteresis will be used with single-feature modified z-scores as the score function for each physical subsystem. The median and median absolute deviation baselines will be calculated from fault-free data provided by the bio-reactor simulator. The final process will be as follows, it will subscribe to the MQTT broker and listen for data published from the bioreactor to process. When data is gathered, a z-score will be calculated and compared to the two bounds, which will begin or stop marking incoming data as anomalous.

This is the connectivity and user interface subsystem, this includes the physical layer, microcontroller layer, network layer and the application layer. The physical and microcontroller layers are connected by wires, using UART between the ESP32 and Arduino Nano. Between the ESP32, network layer and application layer, the connection is wireless using WiFi and MQTT protocols. The user interface includes the systems dashboard, data analysis charts and the control panel. Anomalous data is displayed and marked on the data analysis charts.
